# eliemulamba.github.io

Personal portfolio of **Elie Ngambwa Mulamba** — Strategic Analysis · Machine Learning Engineer · Geomarketing.

Static, bilingual (English / Français) site with light and dark themes. No build step.

- `index.html` — all content (each text has an `data-l="en"` and `data-l="fr"` version)
- `css/style.css` — styles
- `js/main.js` — language and theme toggles
- `assets/cv/` — downloadable CVs (EN, FR)
- `assets/img/profile.jpg` — portrait

Preview locally:

```bash
python3 -m http.server 8000
```
